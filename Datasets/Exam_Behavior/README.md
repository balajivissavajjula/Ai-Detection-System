# Exam Behavior Dataset

This dataset is used to detect suspicious student behavior during examinations.

## Classes

- cheating
- normal
- cheat_paper
- look_around
- use_phone

## Purpose

The dataset is designed to identify suspicious examination behavior and unauthorized activities.

## Model

YOLOv8

## Dataset

Merged and improved exam behavior dataset.

## Performance

- Precision: 68.90%
- Recall: 52.50%
- mAP@50: 66.40%
- mAP@50-95: 41.80%
